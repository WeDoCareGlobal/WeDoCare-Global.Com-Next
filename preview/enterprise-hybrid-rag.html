Enterprise Hybrid-RAG

Connect enterprise knowledge with hybrid lexical and dense retrieval, fused through RRF.

Control question

Are answers grounded in governed enterprise knowledge?

View retrieval demo View repository

Hybrid retrieval combines BM25 keyword matching with dense semantic embeddings, fused through reciprocal rank fusion (RRF). Every retrieved chunk is traced to its source document with a confidence score.

  • BM25 + dense retrieval (RRF) — keyword and semantic search fused
  • NVIDIA NeMo Retriever embeddings — enterprise-grade vector encoding
  • Multi-modal support — text, charts, structured data
  • RAGAS continuous evaluation — retrieval quality tracked over time
  • SSE streaming — real-time response delivery

Retrieval stack

Four retrieval layers

Lexical (BM25)

  • Keyword-level matching
  • Exact term frequency scoring
  • Field-weighted results

Dense (NeMo)

  • Semantic vector embeddings
  • Cross-encoder reranking
  • Multi-language support

RRF Fusion

  • Reciprocal rank fusion scoring
  • Deduplicated result sets
  • Confidence-weighted ranking

Evaluation

  • RAGAS continuous scoring
  • Faithfulness & precision metrics
  • Regression alerts
How it works

From query to grounded answer.

1

Query received

User or agent submits a natural-language question.

2

Hybrid retrieval

BM25 and dense search run in parallel, results fused via RRF.

3

Source trace

Every returned chunk is linked to its source document.

4

Evaluate & stream

RAGAS scores the result; SSE streams it to the user.
