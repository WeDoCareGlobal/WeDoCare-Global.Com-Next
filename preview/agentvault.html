AgentVault

Bring tool registration, secret management and bounded execution into a clearer control layer.

Control question

Are tool credentials registered, rotated, and bounded?

View bounded execution demo View repository

AgentVault governs how AI tools are registered, how secrets move through them, and how execution stays inside defined boundaries. Every tool call is checked against a registered manifest before it reaches the model.

  • Tool registry with OpenAPI import — declarative tool definitions
  • Secret lifecycle & rotation — credentials never reach the model context
  • Bounded execution envelopes — per-tool time, token, and cost caps
  • RBAC & rate limiting — who can call what, how often
  • Hash-chained audit ledger — tamper-evident record of every invocation

Bounded execution example

A tool requests access to a secret. AgentVault checks registration, scope, and rate limits before returning a scoped credential.
